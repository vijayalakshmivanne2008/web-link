Welcome to Programming Logic

This page introduces basic programming logic concepts with definitions, examples, and step-by-step algorithms. Learn how to solve number-based problems using logical thinking.

1. Prime Number

A prime number is a number greater than 1 that has exactly two factors: 1 and itself.

Examples: 2, 3, 5, 7, 11, 13

Logic

  1. Take an integer as input.
  2. Check whether the number is less than or equal to 1.
  3. Check whether any number from 2 to the square root of the number divides it exactly.
  4. If a divisor exists, it is not prime; otherwise, it is prime.

2. Armstrong Number

An Armstrong number is a number equal to the sum of its digits, each raised to the power of the total number of digits.

Example: 153

153 = 1³ + 5³ + 3³ = 153

Logic

  1. Take a number as input.
  2. Count the number of digits.
  3. Extract each digit.
  4. Raise each digit to the power of the digit count.
  5. Add the results and compare the sum with the original number.

3. Perfect Number

A perfect number is a positive integer equal to the sum of its positive divisors, excluding itself.

Example: 6

6 = 1 + 2 + 3

Logic

  1. Take a positive integer as input.
  2. Find all its positive divisors except the number itself.
  3. Add all the divisors.
  4. Compare the sum with the original number.
  5. If both are equal, it is a perfect number.

4. Reverse Number

Reversing a number means arranging its digits in the opposite order.

Example: 1234 becomes 4321.

Logic

  1. Take a number as input.
  2. Extract the last digit using the remainder operator.
  3. Add the digit to the reversed number.
  4. Remove the last digit using integer division.
  5. Repeat until the number becomes zero.
